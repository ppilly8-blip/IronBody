IronBody is a free, offline-capable no-equipment workout app with routines,
isometric holds, timers, step-by-step guidance, and 74 exercises.

## Downloads

- **Android APK:** [IronBody.apk](https://github.com/ppilly8-blip/IronBody/releases/latest/download/IronBody.apk) (built automatically by GitHub after each push; it appears under Releases once a build has finished)
- **Web app URL (after Pages deployment):** <https://ppilly8-blip.github.io/IronBody/>
- **Latest GitHub release:** <https://github.com/ppilly8-blip/IronBody/releases/latest>

The APK is signed with the included Android debug key for personal installation
and testing. It is not Play Store-signed. GitHub Pages has to be switched on once:
**Settings → Pages → Source: GitHub Actions**.

## Use the web app

The PWA is in `www/` and can be installed from a browser. GitHub Pages publishes
it automatically from `.github/workflows/pages.yml`.

1. Open <https://ppilly8-blip.github.io/IronBody/>
2. On Android Chrome, use the browser menu and choose **Install app**.
3. On iPhone Safari, use **Share** -> **Add to Home Screen**.
4. On desktop Chrome or Edge, use the install icon in the address bar.

After its first visit, the app uses an offline cache. Internet is still needed
for remotely loaded Wikipedia exercise photographs.

## Timers and progress

- Timed exercises start their own countdown (**AUTO**): a short get-ready count,
  then the hold. Tap the **AUTO** pill on the timer card to switch to **MANUAL**
  and press START TIMER yourself.
- **Progress** counts only sets you really finish. Opening a routine, pressing
  START or skipping an exercise adds nothing. Each finished set is saved on the
  phone at that moment, and the days, streak, muscle focus and badges are worked
  out from those saved sets.
- Progress stays on the device (nothing is uploaded) and is kept when a newer
  build is installed over the old one. Clearing the app's data or uninstalling it
  erases it, and so does **Reset progress** on the Progress page.

## Install the Android app

1. Download [IronBody.apk](https://github.com/ppilly8-blip/IronBody/releases/latest/download/IronBody.apk).
2. Open it on an Android phone.
3. Allow installation from the browser or Files app if Android requests it. If Play Protect says "unknown developer", choose **Install anyway**.

A newer build installs over the old one and keeps your data, because every build
is signed with the same key and gets a higher version number.

## Project layout

- `www/` - web/PWA application
- `scripts/prepare-android.js` - generates and prepares the Android project
- `android-overlay/` - app icons and launch-screen resources
- `keystore/debug.keystore` - fixed debug signing key
- `android/` - generated by Capacitor, ignored by Git
- `.github/workflows/pages.yml` - publishes the web app
- `.github/workflows/build-apk.yml` - builds and publishes the APK

## Build locally

Requirements:

- Node.js 22 or newer
- JDK 21
- Android SDK with platform 36 and build-tools 36.0.0

```bash
npm ci
npm run android:prepare

# Point JAVA_HOME at JDK 21 and ANDROID_HOME at your Android SDK folder first.
cd android
./gradlew assembleDebug --no-daemon
```

The APK is written to:

```text
android/app/build/outputs/apk/debug/app-debug.apk
```

## Automatic builds

Pushing to `main` or `master` runs both GitHub Actions workflows.

- `Publish web app` deploys `www/` to GitHub Pages.
- `Build Android APK` creates `IronBody.apk`, uploads it as a workflow artifact,
  and publishes it as a GitHub release asset.

GitHub Pages must have **Source: GitHub Actions** selected in repository settings.
If `Publish web app` failed before that was switched on, open it under the
**Actions** tab and press **Re-run all jobs**.
