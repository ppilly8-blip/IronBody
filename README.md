IronBody is a free, offline-capable no-equipment workout app with routines,
isometric holds, timers, step-by-step guidance, and 74 exercises.

## Downloads

- **Android APK:** [IronBody.apk](./IronBody.apk)
- **Web app URL (after Pages deployment):** <https://ppilly8-blip.github.io/IronBody/>
- **Latest GitHub release:** <https://github.com/ppilly8-blip/IronBody/releases/latest>

The APK is signed with the included Android debug key for local installation
and testing. It is not Play Store-signed. The public Pages site is not yet
deployed and returned 404 during validation; push the workflows to GitHub and
enable Pages with **Source: GitHub Actions**.

## Use the web app

The PWA is in `www/` and can be installed from a browser. GitHub Pages publishes
it automatically from `.github/workflows/pages.yml`.

1. Open <https://ppilly8-blip.github.io/IronBody/>
2. On Android Chrome, use the browser menu and choose **Install app**.
3. On iPhone Safari, use **Share** -> **Add to Home Screen**.
4. On desktop Chrome or Edge, use the install icon in the address bar.

After its first visit, the app uses an offline cache. Internet is still needed
for remotely loaded Wikipedia exercise photographs.

## Install the Android app

1. Download [IronBody.apk](./IronBody.apk).
2. Open it on an Android phone.
3. Allow installation from the browser or Files app if Android requests it.

The generated APK is a 4.1 MB debug APK and was signed and verified locally.

## Project layout

- `www/` - web/PWA application
- `scripts/prepare-android.js` - generates and prepares the Android project
- `android-overlay/` - app icons and launch-screen resources
- `keystore/debug.keystore` - fixed debug signing key
- `android/` - generated by Capacitor, ignored by Git
- `.github/workflows/pages.yml` - publishes the web app
- `.github/workflows/build-apk.yml` - builds and publishes the APK
- `IronBody.apk` - verified local APK

## Build locally

Requirements:

- Node.js 22 or newer
- JDK 21
- Android SDK with platform 36 and build-tools 36.0.0

```bash
npm ci
npm run android:prepare

export JAVA_HOME=/usr/local/sdkman/candidates/java/21.0.13.0+2-ms
export ANDROID_HOME="$HOME/android-sdk"
export ANDROID_SDK_ROOT="$ANDROID_HOME"

cd android
./gradlew assembleDebug --no-daemon
```

The APK is written to:

```text
android/app/build/outputs/apk/debug/app-debug.apk
```

## Automatic builds

Pushing to `main` or `master` runs both GitHub Actions workflows.

- `Publish web app` deploys `www/` to GitHub Pages.
- `Build Android APK` creates `IronBody.apk`, uploads it as a workflow artifact,
  and publishes it as a GitHub release asset.

GitHub Pages must have **Source: GitHub Actions** selected in repository settings.
